# Как добавить новую работу

Чтобы добавить новую работу:

1. Возьми данные от пользователя: название, категорию, клиента, описание, стек, ссылку (если есть), дату, превью.
2. Сформируй id в виде slug. Проверь, что такого id ещё нет.
3. Конвертируй превью в WebP, сохрани в `public/portfolio/<id>.webp`, ширина до 1200 px, соотношение 4:3. Если превью не передано, используй плейсхолдер и отметь это в ответе.
4. Добавь объект в конец `src/data/projects.json` строго по схеме из раздела ниже. Существующие записи не меняй.
5. Не трогай верстку, компонент `ProjectCard`, стили и структуру секции. Если для работы нужно что-то поменять в шаблоне, сначала спроси.
6. Если это первая реальная работа, удали демонстрационную запись с полем `example: true`.
7. Запусти сборку и линтер. Убедись, что в новой карточке нет обрезанного текста и поломанной сетки на мобильной ширине.
8. Коммит в ветку `test/landing` с сообщением `add project: <title>`. Пуш в main не делать.

## Схема записи (src/data/projects.json)

Один проект = один объект со строго одинаковым набором полей:

| Поле | Тип | Обязательное | Правило |
|---|---|---|---|
| `id` | string | да | slug латиницей, например `landing-coffee-shop`; уникальный |
| `title` | string | да | название работы |
| `category` | string | да | одно из значений: `landing`, `bot`, `layout`, `script` |
| `client` | string | нет | тип клиента или проекта, например «Кофейня» |
| `description` | string | да | 1–2 предложения о задаче и результате |
| `stack` | string[] | да | технологии |
| `cover` | string | да | путь к превью, например `/portfolio/landing-coffee-shop.webp` |
| `link` | string | нет | ссылка на демо или кейс |
| `date` | string | да | год и месяц, формат `2026-03` |
| `featured` | boolean | да | показывать ли в начале списка |
| `example` | boolean | нет | допускается только у одного демонстрационного проекта |

Пример записи:

```json
{
  "id": "landing-coffee-shop",
  "title": "Кофейня «Зерно»",
  "category": "landing",
  "client": "Кофейня",
  "description": "Лендинг для локальной кофейни: меню, атмосфера и заявка на бронь столика.",
  "stack": ["Astro", "Tailwind CSS", "TypeScript"],
  "cover": "/portfolio/landing-coffee-shop.webp",
  "link": "",
  "date": "2026-03",
  "featured": false,
  "example": true
}
```

Правила:

- Новые работы всегда добавляются в конец массива. Внутри группы порядок отображения совпадает с порядком в файле; записи с `featured: true` показываются в начале (стабильная сортировка).
- Поле `example: true` допускается только у одного демонстрационного проекта, который при первом реальном добавлении удаляется.
- Превью: `public/portfolio/<id>.webp`, ширина не более 1200 px, соотношение сторон 4:3, имя файла совпадает с `id`.
- Перед сборкой работает валидатор (`npm run validate`): он проверит схему, уникальность id, формат даты, наличие файла превью и единственную запись `example`.
- Быстрая конвертация превью: `npm run cover -- <путь-к-исходнику> <id-проекта>` — кроп по центру до 1200×900 и WebP.

Проверить результат после добавления: `npm run validate && npm run build && npm run lint`.
